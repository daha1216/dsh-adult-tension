| **角色态度** | 无底线顺从，有求必应 | 每个 NPC 有目标和底线；回应分拒绝、协商、有限配合、表面配合、真诚配合五档 |
| **成人内容** | 写到关键处一句带过，或突然跳到“事后” | **尺度由你定**：不强制淡出，你要求写到哪步就写到哪步；全员成年、同意可撤回、硬边界由引擎执行 |
| **长线记忆** | 聊十几轮就失忆，关系与设定漂移 | 人物、关系、时间、事实都存在本地 SQLite；每回合上下文不超过 20 KB |

**开一局**

| 你说 | 会发生什么 |
|:---|:---|
| `开局` | 完全随机；会先问你选“日常”还是“有压力” |
| `开局，港口夜班` | 指定世界 |
| `开局，不要职场` | 排除题材 |
| `开局，我是三十岁的女摄影师` | 设定你自己 |
| `自定义世界，民国的一座山城……` | 模型当场写一个世界，只属于这一局 |
| `重开 42 号` | 同一种子，原样重来 |

**推进剧情**

新局依次给出“世界观”“人物”和正文，正文停在一个等你接手的动作上。直接写动作或台词：

```text
我走到她面前，把文件放在桌上：“我们单独谈谈。”
```

**随时调整**

| 你说 | 会发生什么 |
|:---|:---|
| `继续` · `c` | 向前推一幕，场面里至少有一处变化 |
| `快进到明天早上` | 不在场的人各有动静，到期的事有结果 |
| `状态` | 关系、承诺、风声、快到期的事 |
| `存档` · `qs` | 存到当前存档槽 |
| `另存为 名字` · `读档 名字` | 另存一条分支，或从那一刻接着玩 |
| `存档列表` | 所有存档 |
| `导出` · `导入` | 导出存档文件，换台电脑也能续 |
| `刚才不算` | 撤销或改写上一回合 |
| `内心可见 开` · `暂停` · `边界：不要 X` | 看见没说出口的话；立刻停下；划一条引擎替你守的线 |

同一个存档被另一个窗口改过时，会提示你读最新版、另存为，或取消，不会静默覆盖。

<details>
<summary><b>存档在哪里，升级会不会丢</b></summary>
<br>

存档永远不放在 Skill 目录里，升级、卸载都不会动它。

| 系统 | 数据目录 |
|---|---|
| Windows | `%LOCALAPPDATA%\adult-tension` |
| macOS | `~/Library/Application Support/adult-tension` |
| Linux | `$XDG_DATA_HOME/adult-tension`，未设置时 `~/.local/share/adult-tension` |

也可以用环境变量 `ADULT_TENSION_HOME` 或参数 `--data-dir` 指定。升级就是替换 Skill 目录；数据库格式变了会先自动备份再迁移，失败就恢复。

</details>

### 用什么模型玩

出文效果随模型版本、上下文长度和平台配置变化；对话越深，角色一致性和语感越依赖模型本身。时间线、关系和存档由本地引擎守着，换模型也不会丢。上面的实录用的是 gemini-3.8-flash。

### 使用边界

- **仅限成年人。** 所有人物与情节均为虚构，全员成年；同意随时可以撤回；硬边界由引擎执行，不靠模型自觉。
- **需要一个能运行本地命令的 Agent 宿主**，比如上表里的几个。宿主怎么把对话发给模型，由宿主和你选的模型服务决定；存档只存在你自己的电脑上。
- **出文质量取决于模型。** 引擎保证事实不漂移，文笔和分寸还是模型的事。
