> [!IMPORTANT]
> **仅限成年人。** 这是一个面向成年人的中文互动叙事项目，内容涉及亲密关系与欲望。所有角色都是明示的成年人。未满 18 岁请离开。

<br>

## 它是什么

你在 Claude Code、Codex、OpenCode 这类 AI 宿主里说一句“开局”，就走进一个有生活质感、有人物意志、会自己运转的世界。你扮演其中一个成年人，和几位成年 NPC 在日常、职业、利益、欲望与秘密之间慢慢形成张力——每一次靠近和后退，都会留下记录、产生后果。

整个项目只有一条分工：

<picture>
  <source media="(prefers-color-scheme: dark)" srcset=".github/readme/flow-dark.svg">
  <img alt="玩家 → 宿主里的模型 → 本地运行时" src=".github/readme/flow-light.svg" width="100%">
</picture>

**模型写故事，引擎守事实。** 模型负责理解你、决定 NPC 怎么回应、写正文；随 Skill 附带的本地运行时负责人物、关系、时间、事件、边界和存档。模型提交的是“操作”，不是“状态”——违反规则的操作会被引擎拒绝，所以长局不会失忆，也不会自相矛盾。

## 安装

需要 **Python 3.10 或更高**，只用标准库，不需要 `pip install`，也不用设环境变量、建数据库。安装就是把 `skill/adult-tension/` 这个目录放进宿主的 Skill 目录。

```bash
git clone --depth 1 https://github.com/daha1216/dsh-adult-tension.git
```

以 Claude Code 为例：

```bash
cp -r dsh-adult-tension/skill/adult-tension ~/.claude/skills/
```

然后在宿主里开一个新对话，说一句“看看 Adult Tension 能不能用”。没有宿主、只有命令行也行：

```bash
python dsh-adult-tension/skill/adult-tension/scripts/adult_tension.py doctor --json
```

<details>
<summary><b>存档放在哪里，升级和卸载会不会丢档</b></summary>
<br>

存档永远不放在 Skill 目录里：

| 系统 | 数据目录 |
|---|---|
| Windows | `%LOCALAPPDATA%\adult-tension` |
| macOS | `~/Library/Application Support/adult-tension` |
| Linux | `$XDG_DATA_HOME/adult-tension`，未设置时 `~/.local/share/adult-tension` |

也可以用环境变量 `ADULT_TENSION_HOME` 或参数 `--data-dir` 指定。

- **升级**：用新的 Skill 目录替换旧的。数据库格式变了会先自动备份再迁移，迁移失败就恢复备份。
- **卸载**：删掉 Skill 目录。存档留着，清除数据是单独的、需要确认的操作。

</details>

## 怎么玩

直接说话就行。下面这些说法宿主都认得：

| 你说 | 会发生什么 |
|---|---|
| `开局` · `开局 压力` · `开局 港口` · `重开 12 号` | 开一局。没说模式会先问一句“1 日常 / 2 有压力” |
| `开局，不要职场` · `女性 NPC 为主` · `我是三十岁的女摄影师` | 排除题材、指定配对偏好、设定你自己 |
| 任何行动或对白 · `继续` | 推进一回合 |
| `快进到晚上` · `跳到第二天` · `来点转折` | 时间往前走，不在场的人也各有动静 |
| `存档` · `读档` · `存档列表` · `导出` | 存读档；隔天说“继续上次”接着玩 |
| `状态` · `状态+` | 看关系、承诺、风声、到期的事 |
| `内心可见 开` · `语态 某人 里` | 看见没说出口的话；切换某人的表层与里层 |
| `刚才不算` · `其实……` | 撤销或改写上一回合 |
| `世界列表` · `自定义世界 ……` · `帮助` | |

## 边界与安全

<table>
<tr>
<td width="33%" valign="top">

**全员成年**<br>
<sub>每个角色都是明示的成年人。校验器会扫描未成年暗示，带这类内容的世界包无法通过。</sub>

</td>
<td width="33%" valign="top">

**硬边界由引擎执行**<br>
<sub>说“边界：不要 X”，之后任何越界的提交都会被引擎直接拒绝，不靠模型自觉。</sub>

</td>
<td width="33%" valign="top">

**随时暂停**<br>
<sub>说“暂停”或你的安全词，场面立刻停下、回到中性叙述；“换个场景”会转去别处。</sub>

</td>
</tr>
</table>

同意可以随时撤回。亲密只来自人物本身的意愿；即使世界的前提里有胁迫，它也只是背景，不会成为亲密的来源。

## 开发

```
skill/adult-tension/     可安装的 Skill：SKILL.md、references/、runtime/、编译好的世界包
content-src/worlds/      世界包源文件（JSON）
tools/                   编译、校验、开局预览、模拟、基准测试、安装
tests/                   core · content · integration · e2e
spec/                    需求规范，唯一的需求来源
PROGRESS.md              进度、执行过的命令、实际数字、待决事项
```

运行时只用 Python 标准库；SQLite 是唯一的状态存储，状态只有一个写入口。每个写操作都带 `request_id`，会话内的写操作还带 `expected_revision`，重试不会重复推进回合。每回合给模型的上下文有固定预算，不随局长膨胀。

```bash
python -m unittest discover -s tests/core
```

```bash
python -m unittest discover -s tests/content
```

```bash
python tools/validate_skill.py skill/adult-tension
```

想加一个世界？读 `spec/CONTENT_BIBLE.md`：从 `tools/new_world.py` 起草，用 `tools/preview_openings.py` 逐条读开局，过了校验和开局多样性门禁，再经真实试玩，才能从 `review` 转为 `released`。
