# P0 优化功能说明

本文档说明 P0 优化方案的实现细节。这些功能已集成到主 SKILL.md 中。

## 1. 命令系统优化（已实现）

### 命令别名与分类

详见 `commands.yaml` 配置文件。所有命令按功能分类：

- **元指令**：存档、载入、状态查询、帮助
- **游戏指令**：继续、快进、撤销
- **边界管理**：设置/解除硬边界、暂停/恢复
- **高级功能**：语态切换、视角模式、世界推演、叙事助手
- **存档管理**：存档、载入、命名存档、列出存档

### 常用简写

```
s   → 存档
l   → 载入
c   → 继续
h   → 帮助
?   → 帮助
qs  → 快速保存
```

### 使用示例

```
用户输入: s
系统识别: 存档命令
执行: 输出完整 v3 YAML

用户输入: 状态+
系统识别: 增强状态查询
执行: 显示状态 + 许可 + 待办 + 事件前3项
```

## 2. 状态可见性分级（已实现）

### 三级查询

| 命令 | 内容 | 用途 |
|------|------|------|
| 状态 | 地点、参与者、暂停状态、压力、可接续动作 | 快速定位 |
| 状态+ | 上述 + 当前许可、待办摘要(≤3)、事件队列前3项 | 决策辅助 |
| 调试 | 上述 + 关系数值、自主冷却、完整事件队列 | 高级用户 |

### 输出格式示例

#### 状态（基础）
```
📍 李悦的办公室
👥 你、李悦
💭 当前可以：深入探索她的反应 / 推进时间到晚饭 / 转移话题到工作
```

#### 状态+（增强）
```
📍 李悦的办公室  👥 你、李悦
✓ 已同意：亲密接触  ⏳ 待确认：更深入行为
📋 待办：2 回合内完成提案（第 12 回合承诺）
⏰ 即将：约 3 回合后李明可能主动联系
💭 当前可以：深入探索她的反应 / 推进时间到晚饭 / 转移话题到工作
```

#### 调试（完整）
```
📍 李悦的办公室  👥 你、李悦
✓ 已同意：亲密接触  ⏳ 待确认：更深入行为

关系状态：
- 李悦：信任 75, 吸引 60, 权力差 -15

自主冷却：
- 李悦：上次第 12 回合，冷却至第 15 回合

待办事项：
1. 完成提案（来源：第 12 回合承诺，剩余 2 回合）
2. 晚饭后去她家（来源：第 15 回合她的要求，剩余 5 回合）

事件队列：
1. [第 18 回合] 李明主动联系
2. [第 20 回合] 提案截止
3. [第 25 回合] 部门会议

💭 当前可以：深入探索她的反应 / 推进时间到晚饭 / 转移话题到工作
```

### 实现要点

- 使用自然语言和 emoji，不暴露字段名
- "状态+"在不暴露后台机制的前提下提供决策信息
- 待办事项显示来源和剩余回合
- 事件队列只显示前 N 项，避免信息过载

## 3. 存档系统简化（已实现）

### 三命令

玩家只需要记住三个存档命令：

```
存档 / 保存 / s       → 保存到当前存档（输出完整 v3 YAML）
载入 / l              → 载入存档
列出存档              → 显示所有命名存档
```

便捷命令：

```
保存 X / 另存为 X     → 保存为命名存档 X
载入 X / 读取 X       → 载入命名存档 X 并绑定为写入目标
快速保存 / qs         → 快速保存到当前存档（距上次 > 5 回合或危险操作前自动提示）
```

后台由 `scripts/manage_saves.py` 原子写入 `saves/slots/<名称>/`；命名存档之间彼此隔离，需要继续已有主线时明确“载入 X”。

### 版本冲突的友好提示

**当前技术向提示**：
```
保存冲突，请载入最新版本后再保存
```

**优化后用户友好提示**：
```
该存档被其他窗口修改过（第 15 回合），你的进度是第 12 回合。
要：
A. 读取其他窗口的最新版本（你的修改会丢失）
B. 把你的版本另存为其他名称继续
C. 取消保存
```

### 自动提示机制

```python
# 在以下情况提示快速保存：
if 距离上次保存 > 5回合:
    提示 = "距上次保存已 5 回合，要【快速保存 qs】吗？"

if 用户尝试危险操作:
    提示 = "这可能改变局势，要先【快速保存 qs】吗？"
```

危险操作包括：
- 重大决定（明确承诺、换场、关键选择）
- 场景许可升级
- 冲突升级

## 4. 帮助命令优化

### 按分类显示

输入 `帮助`、`命令` 或 `h` 时，按 commands.yaml 的分类结构输出：

```
📖 可用命令

== 基础操作 ==
继续 (c / ...)    - 推进一个动作节拍
快进到...        - 更新时间并追算
撤销             - 撤销最近事件

== 状态查询 ==
状态             - 查看当前情况
状态+            - 增强查询（含许可、待办）
调试             - 完整状态（含数值）
帮助 (h / ?)     - 显示此帮助

== 存档管理 ==
快速保存 (qs)    - 快速保存到当前存档
保存 X           - 保存为命名存档 X
存档 (s)         - 输出完整 YAML 并存档
载入 (l)         - 读取存档
列出存档         - 显示所有命名存档

== 边界与安全 ==
本局不碰 X       - 设置硬边界
暂停             - 停止亲密升级
解除暂停         - 恢复场景

== 高级功能 ==
说骚话           - 角色切入里层语态
贴视角           - 开启内心可见
叙事助手 on      - 开启每回合建议

💡 行动句规则：
- 明确动作 → 结果成立（除非硬冲突）
- "尝试、试着" → 由 NPC 判定
- "必须、确保" → 锁定结果
```
