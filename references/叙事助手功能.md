# 叙事助手功能

## 概述

叙事助手是可选的每回合建议系统，帮助不熟悉叙事游戏的用户理解当前可选动作。默认关闭，通过命令开启。

## 启用/禁用

```
叙事助手 on    → 开启每回合后的建议
叙事助手 off   → 关闭建议
```

## 输出格式

当叙事助手开启时，在每个有效回合的正文结尾、回合号之后，附加一行建议：

```
<正文>

回合：15

💡 当前可以：深入探索她的反应 / 推进时间到晚饭 / 转移话题到工作
```

## 建议生成规则

### 基于当前场景

建议必须基于当前实际场景状态生成，包括：
- 当前地点和参与者
- 场景许可状态（已同意/待确认）
- 未兑现的跨回合承诺
- 即将触发的事件（前 3 项）
- NPC 情绪和关系状态

### 建议类型

提供 3-4 个具体可行的动作方向，覆盖不同叙事轴：

1. **关系深化**：基于当前许可和 NPC 状态
   - 已同意亲密接触 → "深入探索她的反应"
   - 表层语态 → "引导她放松一些"
   - 里层语态 → "回应她的直白"

2. **时间推进**：基于未完成事项和事件
   - 有待办 → "推进到下一个关键节点"
   - 有即将事件 → "等待即将发生的事情"
   - 无紧迫事项 → "快进到晚饭 / 第二天"

3. **话题转移**：基于场景和关系
   - 办公室 → "转移话题到工作 / 聊聊她的项目"
   - 餐厅 → "聊聊食物 / 童年记忆"
   - 私人空间 → "谈谈更私密的话题"

4. **主动行动**：基于角色能力和场景
   - "提出新的建议"
   - "主动邀请她做某事"
   - "坦白你的想法"

### 生成示例

#### 场景 1：办公室，亲密许可待确认
```
💡 当前可以：试探她的想法 / 推进时间到下班 / 转移话题到工作 / 提出晚餐邀请
```

#### 场景 2：餐厅，已同意亲密接触
```
💡 当前可以：深入探索她的反应 / 聊聊更私密的话题 / 提议换个地方 / 等她主动
```

#### 场景 3：私人空间，里层语态激活
```
💡 当前可以：回应她的直白 / 推进到下一阶段 / 让她主导节奏 / 暂停喘口气
```

#### 场景 4：有紧迫待办事项
```
💡 当前可以：完成提案（2 回合内）/ 先处理工作再继续 / 快进到提案完成后 / 请她帮忙
```

## 实现要点

### 不暴露后台机制

建议使用自然语言，不暴露：
- 字段名（scene_id、consent_state）
- 数值（关系 75、吸引 60）
- 状态码（pending、blocked）
- 档位名称（真诚配合、表面配合）

❌ 错误示例：
```
💡 当前可以：提升 attraction 数值 / 触发 pending 事件 / 达成真诚配合档位
```

✓ 正确示例：
```
💡 当前可以：深入探索她的反应 / 推进到约好的时间 / 建立更深的信任
```

### 动态适应场景

建议必须反映当前实际状态：
- 场景许可改变 → 建议相应调整
- NPC 情绪变化 → 建议语气匹配
- 危险操作前 → 加入"快速保存"提示

### 与"状态+"区分

- **状态+**：客观呈现当前状态（地点、许可、待办、事件）
- **叙事助手**：主观建议下一步动作方向

状态+ 回答"现在是什么情况"，叙事助手回答"接下来可以做什么"。

## 触发条件

只在以下情况输出建议：
- 叙事助手已开启（`narrative_assistant: on`）
- 当前回合是有效回合（推进了 meta.turn）
- 正文已成功输出

不在以下情况输出建议：
- 元指令（存档、查看状态、帮助等）
- 开局回合（回合 1 已有足够引导）
- 暂停状态（safety_state: paused）
- 载入存档后的第一回合（等玩家熟悉状态）

## 特殊情况处理

### 危险操作前

距上次保存 > 5 回合，且即将进入高风险场景时：

```
💡 当前可以：深入探索她的反应 / 推进时间到晚饭 / 先【快速保存 qs】
```

### 冲突场景

NPC 反对或谈判时：

```
💡 当前可以：尊重她的想法 / 解释你的理由 / 换个方式尝试 / 暂时退让
```

### 里层语态首次激活

角色首次切入里层语态时：

```
💡 当前可以：回应她的坦率 / 保持表层回应 / 试探她的底线 / 让她继续
```

### 跨回合承诺即将到期

距离承诺到期 ≤ 2 回合时：

```
💡 当前可以：完成提案（剩余 2 回合）/ 向她坦白来不及了 / 快进完成 / 请求延期
```

## 后台状态维护

系统需要维护：
```yaml
narrative_assistant:
  enabled: false  # 默认关闭
  last_suggestions: []  # 上次建议（避免重复）
  context_hash: ""  # 场景哈希（检测场景变化）
```

场景哈希基于：
- current_node.location
- current_node.participants
- scene_id
- 当前场景许可状态
- 未兑现承诺数量
- 最近事件类型

场景哈希变化时，允许重复之前的建议类型（但措辞应不同）。

## 用户反馈循环

系统可记录用户实际采纳的建议类型，用于优化后续建议：

```yaml
assistant_stats:
  suggestion_used:
    关系深化: 12
    时间推进: 8
    话题转移: 5
    主动行动: 15
```

但这是可选的统计功能，不影响核心叙事逻辑。
