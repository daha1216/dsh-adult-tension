## 世界核心规则轴

用四个短轴说明什么规则改变了日常、谁能掌握或必须遵守、付出什么代价，以及它正在如何变化；结果须合成一条因果世界常量，不逐项堆进正文。

- 核心规则来源：制度门槛、稀缺资源、基础设施、家族传统、行业规范、生态条件、公共危机、舆论机制、代际契约
- 掌握范围：人人遵守、专业群体掌握、单一组织垄断、地域限定、资格审查后开放、地下流通
- 生效代价：金钱、时间、身份义务、声誉风险、关系承诺、身体负担、信息暴露
- 变化阶段：稳定运行、刚刚出现、快速普及、监管收紧、秩序失效、替代制度萌芽

### 半架空增补

- 核心规则来源：异常能力、特殊感染、秘密技术、超常器物、隐秘机构、集体潜意识
- 掌握范围：持证者可用、少数觉醒者掌握、机构秘密管控、特定区域生效
- 生效代价：记忆损耗、感官负担、能力反噬、异常痕迹
- 变化阶段：秘密曝光前夜、登记制度初建、异常扩散中、管控体系松动

### 强架空增补

- 核心规则来源：魔法法则、血统权能、神明契约、系统规则、种族天赋、世界边界、命运编织
- 掌握范围：特定血统继承、职业阶位开放、神殿或王权垄断、跨种族共同遵守、领域内强制生效
- 生效代价：寿命、灵魂印记、力量反噬、誓约义务、世界排斥
- 变化阶段：法则苏醒、旧神退场、契约体系崩解、世界合并中、纪元更替前夜

## 张力引擎

先抽取 9 个核心族之一，再抽取其下具体项。四级标题只整理原有方向，不作为一级骰结果；半架空与强架空增补只向对应核心族增加具体项，不增加新的核心族。

### 1. 权力与控制

#### 权势结构

1. 名义上级与实际控制者不一致
2. 一方掌握程序许可，另一方掌握现场资源
3. 公开身份高低与私下依赖相反
4. 临时代理权将在期限后失效
5. 多方争夺同一人的支持或证词
6. 权力来源合法，但使用方式会损害声誉

#### 照护与控制权

1. 双方争夺同一空间、资源或决定权
2. 公共权限与私人权限范围不一致
3. 必须重新定义谁可以进入、使用或决定某件事
4. 保护对方会逐渐限制对方的选择
5. 照护者的动机同时包含责任和私人愿望
6. 一旦照护关系公开，双方都要承担社会后果

#### 规则与例外

1. 制度要求一致处理，但某人获得特殊待遇
2. 例外能解决当前问题，却会破坏规则的可信度
3. 角色必须决定公开例外还是隐瞒来源
4. 例外被撤销后，依赖它的人会立即失去保护

### 2. 身份与义务

#### 身份契约

1. 公开关系与真实合作不一致
2. 旧承诺与新身份发生冲突
3. 双方共同维持一套对外说法，但其中有一个洞，谁都不提，两人都清楚
4. 一方需要另一方承认某种名分，另一方拒绝定义

#### 责任与义务

1. 个人愿望与身份职责发生冲突
2. 帮助一方会让另一方违反对组织的承诺
3. 角色必须在公开责任和私人选择之间取舍
4. 失职会牵连无关人员或担保人

#### 名分与承认

1. 一方要求公开名分，另一方只肯给私下事实
2. 旧身份对应的责任被新关系重新要求履行
3. 承认关系等于承认某个不愿承担的责任
4. 名分一旦确立，就无法继续对第三方含混带过

### 3. 资源与依赖

#### 资源锁

1. 关键证据只有一份
2. 通行资格必须由特定人物担保
3. 资金、药物、设备或住处存在单点依赖

#### 交换与代价

1. 获得关键资源必须付出另一种资源
2. 交换条件本身可能暴露真实关系
3. 一方把交换当终点，另一方把同一交换当下一轮要价的起点
4. 双方各持一半资源，单独都无法完成目标
5. 替代方案更安全，但会让目标变得更昂贵

#### 依赖与撤离

1. 一方需要另一方，但又想恢复独立
2. 帮助越多，关系越难回到原状
3. 退出会失去资源、保护或情报
4. 继续依赖会产生新的责任和情感风险

### 4. 时限与取舍

#### 时空锁

1. 必须在天亮前完成
2. 每次见面只有固定短窗口
3. 地点即将封闭或转移
4. 两地时间流速或通信延迟不同
5. 唯一的联系窗口依赖第三方转递，转递者有自己的意图
6. 两人必须同时出现在不同地点，只有一人能去

#### 选择与不可逆

1. 当前决定会关闭未来的一条路径
2. 公开身份、关系或证据后无法完全撤回
3. 不选择也会被解释为一种选择
4. 角色必须在安全方案和真实愿望之间取舍
5. 当前决定需要先披露才能执行，披露本身已是不可逆的一步

### 5. 信息与误解

#### 信息与债

1. 一方知道秘密但不知道秘密的价值
2. 旧债的真实债权人另有其人
3. 消息经由不可靠渠道传播
4. 一方以为账已结清，另一方仍握着未公开的后续条款
5. 证词、录像或记录存在可疑缺口
6. 一方已经泄露了某信息，却不知道对方早已知情，单向信息差正被利用

#### 记忆与解释

1. 同一行为被双方理解成不同含义
2. 一方记得承诺，另一方只记得试探
3. 过去的许可或拒绝被错误延伸到现在
4. 新证据可能迫使角色重写对过去的判断

#### 距离与沟通

1. 双方想表达真实意图，却只能通过第三方传递
2. 面对面更危险，远程沟通又容易误解
3. 必须决定等待确认，还是根据不完整信息行动

### 6. 目标与信任

#### 目标错位

1. 双方都想解决危机，但最终目的不同
2. 一方想保护关系，另一方想利用关系
3. 共同完成短期目标会损害长期目标
4. 双方以为目标一致，实际上对"成功"的定义截然不同

#### 信任与赌注

1. 一方愿意合作，但无法确认另一方是否诚实
2. 关键帮助必须先通过一次可验证的试探
3. 信任上升会开放更多信息，同时增加被背叛的代价
4. 双方都在等待对方先承担风险

### 7. 声誉与关系

#### 声誉与曝光

1. 私下选择可能损害公开身份
2. 关系越接近，越容易被第三方发现
3. 一份记录或照片足以改变公众看法
4. 角色必须决定保留秘密还是主动公开

#### 嫉妒与替代

1. 第三方的出现让一方意识到自己是可替代的，或想让另一方产生这种意识
2. 一方已有替代选项，却没有说出来——沉默本身变成了筹码
3. 嫉妒被压抑，以控制、冷漠或突然疏远的方式显现
4. 两方争夺同一人的注意或资源，谁先开口谁先示弱
5. 双方被公开比较或评分，名次直接等于身价与议价筹码

#### 羞耻与骄傲

1. 一方做了让自己羞耻的事，宁可让对方误解也不能承认
2. 骄傲阻止了主动求助，但不求助的代价在持续累积
3. 表面强硬者最怕被看穿——被看穿的瞬间是本局最大的脆弱点
4. 羞耻和骄傲都属于同一方，另一方只能等，等不到会先离开

### 8. 能力与限制

#### 身体与能力锁

1. 一方必须借助另一方才能稳定能力
2. 特殊环境只允许某类人进入
3. 能力使用会留下可追踪痕迹
4. 一方能感知另一方无法隐藏的状态
5. 身体或能力恢复与某个期限绑定

#### 环境与准入

1. 某种能力只在特定场所或时段可用，离开就失效
2. 进入关键区域需要对方的资格、身体在场或许可
3. 连续使用能力会触发冷却、损耗或自伤
4. 能否进入或停留，本身就是双方当前最大的限制

### 9. 成人关系张力

#### 欲望与自主

> 侧重欲望的心理博弈与筹码；生理依赖与戒断见「感官与成瘾」。

1. 一方对另一方的身体有契约性使用权，但使用权不等于当前同意
2. 公开身份要求禁欲或贞洁，私下欲望已经无法压抑
3. 欲望强弱倒置：表面强势者其实是更渴求的一方
4. 一方掌握让对方动情的手段，自己却被禁止动情
5. 一次越界让双方再也无法回到不牵涉肉体的关系
6. 满足对方欲望的代价，是放弃自己的某项自主或关系

#### 感官与成瘾

> 侧重生理层面的依赖与戒断；欲望的心理博弈见「欲望与自主」。

1. 一方对另一方提供的某种感官体验产生依赖，离开就戒断
2. 一方故意只给"刚好不够"的满足，维持渴求不动摇
3. 一方需要对方在场才能达到某种身体状态或释放
4. 成瘾程度让强者不得不反过来服从弱者
5. 戒断与重来反复，每轮都陷得更深
6. 第三方以"断供"作为控制手段，被依赖者被迫站队

#### 凝视与展演

1. 一方必须被公开评价外表、姿态或表现，评价权在另一方手里
2. 镜头、评审席或监控在场，私密动作会被放大成公共材料
3. 展演分数或名次绑定现实利益，身体呈现成为交涉筹码
4. 双方都知道观众在看，却必须装作只是工作
5. 被看本身合法且必须，但谁有权决定”看到哪一步”尚未谈妥
6. 一次失态或走光会被记入公开记录，却又有人想利用它

### 半架空增补

#### 权力与控制

1. 异常能力与机构控制：能力可用，但登记、评估或监管会限制选择
2. 保护与监管冲突：组织提供保护，同时要求控制权

#### 身份与义务

1. 正常身份与异常身份冲突：公开生活越稳定，隐藏代价越高

#### 资源与依赖

1. 稳定资源依赖：能力需要特定资源、对象或场所维持

#### 信息与误解

1. 检测与隐瞒：一方能发现异常，另一方必须决定是否暴露

#### 能力与限制

1. 能力使用代价：每次使用都留下可追踪、可见或社会性后果

### 强架空增补

#### 权力与控制

1. 种族与阶位：出身影响法律、资源与社会关系
2. 法则与例外：世界规则稳定，但某人拥有危险的例外资格

#### 身份与义务

1. 契约与自由意志：力量或保护来自契约，但契约限制选择
2. 命定身份与自我选择：预言、血统或职责要求固定道路

#### 时限与取舍

1. 世界边界与迁移：不同领域之间无法自由往来

#### 信息与误解

1. 记忆与身份连续性：过去身份、转生或记忆影响当前关系

#### 能力与限制

1. 力量来源与代价：力量越强，损失越具体
