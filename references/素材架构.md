# 素材架构

本文件是素材维护的总导航。运行时仍按现有 YAML 文件加载；新增素材先确定所属层，再按本文件检查跨层兼容。

机器可读索引见 `references/material_architecture.yaml`，它只引用现有数据路径，不复制素材内容。全量盘点使用 `python scripts/material_inventory.py`；输出包含每个叶级条目的文件、路径、所属层、模式、未归类文件和层级统计，不会被游玩流程加载。八层是逻辑归属，不移动现有文件、不新增抽取阶段，也不改变存档格式。本次只整理非露骨叙事素材的维护入口，其他素材和生成规则保持原状。

维护登记见 `references/material_registry.yaml`，由 `python scripts/material_registry.py --sync` 增量登记。它保留人工决策；变更哈希会使审查失效。只登记来源和治理信息，不复制正文或授予运行资格。

## 1. 世界框架层

文件：`scripts/data/world_frameworks.yaml`

负责定义一个可以独立成立的世界包：时代、规则、美学、社会秩序、地点、人物搭配、日常活动、地方细节，以及压力模式的来源、触发、人物影响和出口。

世界框架必须同时支持：

- 日常模式：有具体活动和自然见面理由，不自动生成外部危机链。
- 压力模式：压力来自框架规则、资源、制度、环境或关系，而不是孤立套用通用压力词。

## 2. 场景空间层

文件：`scripts/data/pools.yaml`、`locations.yaml`、`location_profiles.yaml`

天气、季节与技术边界目前没有统一的独立素材池，可由框架规则和地点细节承载；本次不将其标为已实现的抽取轴。

地点条目负责名称和基本语义；地点画像负责隐私、可见度、见证者、出口、可执行动作和压力修饰。时代专属地点必须同步 `meta.location_eras`。

## 3. 人物层

文件：`identities.yaml`、`identity_profiles.yaml`、`character_meta.yaml`、`character_pools.yaml`、`names.yaml`

人物素材包括玩家身份、NPC身份、社会位置、年龄、称谓、外观气质、性格、资源、目标、边界、说话方式和压力反应。新增人物必须能解释其为何出现在当前地点，以及其能力和限制如何影响活动。

## 4. 关系层

文件：`character_meta.yaml`、`pools.yaml`、`world_frameworks.yaml`

关系素材包括初始关系、相识理由、公开关系、私人期待、信任、信息差、持续往来理由和退出条件。新增关系应能转化为一次自然见面或共同活动。现有来源是 `character_meta.yaml -> 社会位置关系` 与框架 `pairs[].relationship_reason`；信任等动态状态仍归存档，不在素材索引中复制。私人期待、持续往来理由和退出条件目前没有统一的独立素材池，可在关系理由及活动后续中表达。

## 5. 活动与互动层

文件：`action_categories.yaml`、`action_metadata.yaml`、`pools.yaml`、`templates.yaml`

活动是日常和压力模式共用的可玩入口。经营、探索、创作、社交和休闲是选材方向，并非已新增的运行枚举；实际 `category` 继续使用 `action_categories.yaml` 的既有分类，框架活动通过 `places` 和 `pairs` 关联地点与人物。具体动作必须符合人物能力和地点 affordances；涉及压力时再连接压力情境，不把每个活动强制升级为危机。

## 6. 开局情境层

文件：`pools.yaml`、`templates.yaml`、`world_frameworks.yaml`

- 日常：当前活动、相遇契机、新鲜变化、可接手动作、自然后续。
- 压力：压力来源、触发、受影响对象、当下目标、选择、出口和后果。

框架现有字段映射：`source` 是来源；`beats.trigger` 是触发；`beats.objective/choice` 是目标与选择；`beats.immediate/near` 是即时影响及后续；`far_trigger/far_consequence` 是远期压力事件。出口目前写入可选行动与后续文字，没有独立 `pressure_exits` 字段；不要仅新增一个未被读取的字段就声称运行时支持。时限按情境需要填写，不要求所有压力都有倒计时。

压力来源、处境和张力引擎保持分层：来源是外部由头，处境是人物正在承受的问题，张力引擎是整晚的动态戏路。

## 7. 后续变化层

文件：`twists.yaml`、`twist_profiles.yaml`、`references/世界运转.md`

压力转折库负责新信息、第三方介入、资源变化等；日常框架的自然后续来自 `activities.*.beats.near`。索引中的 `modes` 是用途说明，不是新的运行时开关；不会因本次分类让日常开局自动调用压力转折库。人物离屏行动和阶段收束继续由世界运转协议处理。转折必须改变至少一项可观察的事实、选择或后续条件。

## 8. 表达层

文件：`templates.yaml`、`SKILL.md` 及相关 references

负责把已确定的世界、人物、活动和情境写成玩家可见正文。表达模板不能反过来决定世界事实；事实先由素材和状态确定。

## 跨层兼容检查

新增或修改素材后，至少检查：

1. 世界框架与时代、地点、技术、美学、社会规则一致。
2. 地点与人物身份、玩家社会位置、活动和场所条件一致。
3. 人物外观、称谓、身份行为与主题和时代一致。
4. 关系理由能解释双方如何认识、为何继续见面。
5. 日常活动有可执行动作；压力情境有明确出口。
6. 新条目不会与同层条目逐字重复，也不会把压力来源、处境和张力引擎混为一谈。

## 新增素材填写方式

1. 在原数据文件维护内容，按 `references/加内容.md` 补齐现有必填字段。框架内的专属素材留在框架包，不复制到通用池。
2. 新增同一路径下的条目通常无需修改索引；新增数据文件或字段路径时，才同步 `material_architecture.yaml` 的对应层。`path: []` 表示文件根节点，`*` 表示检查所有映射值或列表成员。
3. 两种模式共享项不写来源级 `modes`；仅日常或压力使用的项明确写 `[daily]` 或 `[pressure]`。同一来源可以被不同层引用，不复制正文。
4. 运行下列检查；若实际修改抽取或填料行为，再运行相应开局测试。引用校验不判断文案是否有趣或语义是否合理，这些仍需审读。

验收命令：

```powershell
python -X utf8 scripts/check_content.py
python -X utf8 -m unittest tests.test_material_architecture tests.test_doc_consistency -q
```

`check_content.py` 已调用框架检查；`check_frameworks.py` 不是独立命令行入口。

## 全量维护流程

1. 盘点：`python scripts/material_inventory.py` 扫描全部 YAML 叶字段（含空值和空容器），生成来源路径 ID 和内容哈希；`--summary` 只显示统计。字段数不是独立素材数；列表插入会改变后续路径 ID。
2. 归类：既有选择器提供明确来源，`classification_defaults/overrides` 补充文件与字段所属层。归类默认不授予任何运行模式资格；未知文件继续显示 UNMAPPED。
3. 配套：`python scripts/check_material_compatibility.py` 列出已有地点、活动、人物搭配和压力选项，检查来源标记。名称被引用不等于该素材的整个画像被复用。
4. 校验：先执行上述两条命令，再执行 `python scripts/check_content.py`。重复 YAML 键和失效引用须修复；不能用更新指纹掩盖失败。
5. 抽样：`python scripts/sample_materials.py` 使用固定种子覆盖所有框架和 legacy/auto 的两种模式，不写存档、不生成正文。
6. 发布：执行相关回归与编译检查，确认数据指纹和冻结章节，再提交。全量 JSON 为按需生成的维护产物，不导入游玩上下文。

7. 登记：重新生成维护登记，确认所有新条目都有状态；未完成语义审查的条目保持 `NOT_REVIEWED`，不得用同名引用冒充闭合。
8. 质量审计：运行 `python -X utf8 scripts/material_quality.py --summary`，查看完全重复、近重复和框架同质化候选；该报告只生成候选，不自动合并或删除素材。孤立模板等无效候选必须先登记处置状态，经过一个版本周期和回归验证后再删除。

报告状态：CLASSIFIED 仅表示字段有架构归属；REFERENCED 仅表示对应旧池类型有框架同名引用；UNMAPPED 表示缺少归属或配套证据；BRIDGE 表示现有约束冲突需要人工判断，不是自动放行。NOT_REVIEWED 明确表示未获得逐项语义审查结论。报告保留这些差异，不将全部归类称为全部闭合。
